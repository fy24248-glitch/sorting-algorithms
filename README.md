# Sorting Algorithms (Python)

A beginner-friendly collection of classic sorting algorithms implemented in Python, with a simple test script.

## What's inside
- `bubble_sort.py`
- `selection_sort.py`
- `insertion_sort.py`
- `merge_sort.py`
- `quick_sort.py`
- `binary_search.py` (bonus — searching a sorted array)
- `test_sorts.py` — runs all algorithms on sample input and prints results

## How to run
```bash
python test_sorts.py
```

## Example output
```
Original array: [64, 25, 12, 22, 11, 90, 5]
Bubble Sort:    [5, 11, 12, 22, 25, 64, 90]
Selection Sort: [5, 11, 12, 22, 25, 64, 90]
Insertion Sort: [5, 11, 12, 22, 25, 64, 90]
Merge Sort:     [5, 11, 12, 22, 25, 64, 90]
Quick Sort:     [5, 11, 12, 22, 25, 64, 90]
```

## Why this project
Implementing sorting algorithms from scratch is one of the best ways to understand time complexity (O(n²) vs O(n log n)) and get comfortable with recursion and in-place array manipulation.
